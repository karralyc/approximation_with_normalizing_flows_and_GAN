Топологические ограничения инвертируемых генеративных моделей

Описание проекта

Данный проект содержит реализацию и сравнительный анализ двух генеративных моделей: RealNVP (нормализующий поток) и WGAN-GP (состязательная сеть с градиентным штрафом) на трёх двумерных синтетических датасетах: "two_moons", "gaussian_mixture" и "concentric_circles". Основной целью является демонстрация топологических ограничений инвертируемых моделей на примере концентрических колец. Проект включает инструменты для генерации данных, обучения моделей, вычисления метрик качества и визуализации результатов, а также экспериментальное исследование влияния шума на качество аппроксимации.

Инструкция по запуску

1. Запуск всех экспериментов сразу

Выполните команду:

python run_all.py

Скрипт запустит последовательно обучение RealNVP, WGAN-GP и эксперимент с разными уровнями шума с фиксированным seed=42.

2. Запуск отдельной модели

RealNVP:

python real_nvp.py --seed 42

WGAN-GP:

python wgan_gp.py --seed 42

Эксперимент с шумом:

python exp.py --noise_levels 0.0,0.05,0.1,0.15,0.2 --n_epochs 150

Аргументы:
- --seed: случайное начальное число (по умолчанию 42)
- --noise_levels: уровни шума через запятую (по умолчанию 0.0,0.05,0.1,0.15,0.2,0.25,0.3,0.35,0.4,0.45,0.5)
- --n_epochs: количество эпох обучения (по умолчанию 150)
- --hidden_dim: размер скрытого слоя MLP (по умолчанию 128)
- --n_layers: количество coupling-слоёв (по умолчанию 6)
- --output_dir: директория для результатов (по умолчанию outputs/experiment)

3. Конфигурации моделей

Параметры моделей заданы внутри скриптов.

RealNVP: 6 конфигураций с разным числом слоёв, размером скрытого слоя и использованием BatchNorm.

Конфигурация 1: 4 слоя, скрытая размерность 64, без BatchNorm
Конфигурация 2: 6 слоёв, скрытая размерность 64, без BatchNorm
Конфигурация 3: 6 слоёв, скрытая размерность 64, без BatchNorm
Конфигурация 4: 6 слоёв, скрытая размерность 128, без BatchNorm
Конфигурация 5: 6 слоёв, скрытая размерность 128, без BatchNorm
Конфигурация 6: 6 слоёв, скрытая размерность 128, с BatchNorm

WGAN-GP: 4 конфигурации с разной размерностью латентного пространства и скрытых слоёв.

Конфигурация 1: скрытая размерность 64, латентная размерность 16, learning rate 1e-4
Конфигурация 2: скрытая размерность 128, латентная размерность 16, learning rate 1e-4
Конфигурация 3: скрытая размерность 64, латентная размерность 32, learning rate 5e-4
Конфигурация 4: скрытая размерность 128, латентная размерность 32, learning rate 5e-4

4. Выходные данные

После запуска в папке outputs/ появятся:

- PNG-графики с визуализацией реальных и сгенерированных данных для каждой эпохи
- CSV-файлы с метриками (W1, MMD, KSD, покрытие мод, время обучения) для каждой конфигурации и датасета
- Для эксперимента с шумом: results.csv, config.csv, summary.png, визуализации в папке samples/

Воспроизводимость

Все эксперименты используют фиксированные начальные состояния (seed=42). Для каждой комбинации датасета и конфигурации seed сбрасывается, что обеспечивает полную воспроизводимость результатов. Результаты могут незначительно отличаться из-за стохастичности операций на GPU, но фиксация seed минимизирует эти различия.

Основные результаты

1. Топологическое ограничение: при noise = 0.0 (идеально разделённые кольца) RealNVP не может покрыть обе моды (coverage = 0.0).

2. Роль шума: добавление шума (noise = 0.05) делает носитель распределения связным, и покрытие мод достигает 1.0.

3. Оптимальный уровень шума: минимальное расстояние Васерштейна (W1 = 0.208) достигается при noise = 0.1.

4. Сравнение с GAN: WGAN-GP, не требующая обратимости, достигает покрытия 94.6% при noise = 0.0, в то время как RealNVP — 0.0%.
