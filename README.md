Описание проекта
Этот проект содержит реализацию и сравнительный анализ двух генеративных моделей: RealNVP (нормализующий поток) и WGAN-GP (состязательная сеть с градиентным штрафом) на трёх двумерных синтетических датасетах: "two_moons", "gaussian_mixture" и "concentric_circles". Проект включает инструменты для генерации данных, обучения моделей, вычисления метрик качества и визуализации результатов.

Требования к версиям
Версии компилятора и интерпретатора

Python: 3.13

CUDA (опционально): 11.3+ (для GPU)

Установленные модули
Список основных зависимостей:

torch: 2.9.1
numpy: 2.4.0
scipy: 1.17.0rc2
scikit-learn: 1.8.0
matplotlib: 3.10.8
pandas: 2.3.3
tqdm: 4.67.1
POT: 0.9.6.POST1

Установка зависимостей:

pip install torch numpy scipy scikit-learn matplotlib pandas tqdm POT

Инструкция по запуску
1. Запуск всех экспериментов сразу
Выполните команду:

python run_all.py

Скрипт запустит последовательно оба эксперимента (RealNVP и WGAN-GP) с фиксированным seed=42.

2. Запуск отдельной модели
RealNVP:

python real_nvp.py --seed 42
WGAN-GP:

python wgan_gp.py --seed 42

Аргументы:

--seed: случайное начальное число (по умолчанию 42)

3. Конфигурации моделей

Параметры моделей заданы внутри скриптов:

RealNVP: 6 конфигураций с разным числом слоёв, размером скрытого слоя и использованием BatchNorm.(config)

WGAN-GP: 4 конфигурации с разной размерностью латентного пространства и скрытых слоёв.(config)

4. Выходные данные

После запуска в папке outputs/ появятся:

PNG-графики с визуализацией реальных и сгенерированных данных для каждой эпохи.

CSV-файлы с метриками (W1, MMD, KSD, покрытие мод, время обучения) для каждой конфигурации и датасета.

Примечания

Результаты могут незначительно отличаться из-за стохастичности, но фиксация seed обеспечивает воспроизводимость.
